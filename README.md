# بیلتو — از زمین تا خانه

وب‌اپلیکیشن فارسی و راست‌به‌چپ، بر اساس تصویر مرجع رابط بیلتو. طراحی واکنش‌گرا برای دسکتاپ و موبایل با ناوبری پایین صفحه و منوی کناری.

## اجرا

Node.js نسخه ۲۰ یا بالاتر کافی است؛ نصب وابستگی نیاز نیست:

```sh
node server.mjs
```

سپس `http://localhost:4173` را باز کنید. برای پورت دیگر متغیر محیطی `PORT` را تنظیم کنید. در ویندوز می‌توانید فایل `start-bilto.cmd` را نیز اجرا کنید.

## امکانات

- داشبورد، پروژه‌های نمونه و ایجاد پروژه با اعتبارسنجی اعداد فارسی و انگلیسی
- جزئیات پروژه، مراحل اجرا و تغییر پیشرفت
- محاسبه برآورد هزینه بر اساس مساحت هر طبقه × تعداد طبقات، شهر، سازه و کیفیت
- فهرست مصالح، جست‌وجو، فیلتر، ذخیره علاقه‌مندی و مقایسه تأمین‌کننده
- پروفایل پیمانکار و ذخیره محلی درخواست خرید و مشاوره
- راهنمای ساخت، مقالات، پرسش‌های متداول و جست‌وجو
- ویرایش پروفایل، ترجیحات و خروجی JSON اطلاعات
- صفحه معرفی در `#/landing` و صفحات نمایشی ثبت‌نام، ورود و کد تأیید در `#/register` و `#/login`؛ کد نمونه `12345`
- مانیفست وب‌اپ و ذخیره فایل‌های اصلی برای استفاده آفلاین پس از اولین بارگذاری
- مسیرهای hash برای سازگاری با میزبان‌های استاتیک و GitHub Pages

## محدوده نسخه

این یک فرانت‌اند قابل استفاده با ذخیره‌سازی محلی (`localStorage`) است. اطلاعات بین دستگاه‌ها همگام نمی‌شود. قیمت‌ها، تأمین‌کنندگان، پیمانکاران، امتیازها و پروژه‌های اولیه **نمونه** هستند و به سرویس زنده متصل نیستند. برآوردها نرخ مرجع رسمی یا قیمت روز نیستند و هزینه زمین را شامل نمی‌شوند. درخواست‌ها فقط در مرورگر ثبت می‌شوند و برای هیچ شخص یا شرکتی ارسال نمی‌شوند. احراز هویت و ارسال پیامک واقعی پیاده‌سازی نشده است. برای استفاده عملیاتی، API، پایگاه داده، احراز هویت امن، سرویس پیامک و منبع معتبر قیمت باید افزوده شود.

فونت Vazirmatn از Google Fonts بارگذاری می‌شود و در نبود اینترنت فونت جایگزین سیستم استفاده خواهد شد. تصویرسازی ساختمان و مصالح به صورت SVG داخل کد تولید شده‌اند و نیازمند سرویس عکس نیستند.

## بررسی

```sh
node --test
node --check app.mjs
node --check domain.mjs
node --check server.mjs
```

تست‌ها شامل تبدیل ارقام، محاسبه زیربنای کل، تطبیق جمع تفکیک هزینه‌ها، اعمال ضرایب، ورودی نامعتبر و ایجاد پروژه هستند.

## انتشار استاتیک

فایل‌های `index.html`، `style.css`، `app.mjs`، `domain.mjs`، `icon.svg`، `manifest.webmanifest` و `sw.js` را با حفظ مسیر نسبی روی هر میزبان استاتیک قرار دهید. برای GitHub Pages می‌توان ریشه شاخه اصلی را به عنوان منبع انتخاب کرد. سرور Node تنها برای پیش‌نمایش محلی است و برای میزبانی استاتیک لازم نیست.

## ساختار

`app.mjs`: رابط و تعاملات، `domain.mjs`: محاسبات و داده نمونه، `style.css`: طراحی و واکنش‌گرایی، `server.mjs`: سرور توسعه بدون وابستگی، `domain.test.mjs`: تست منطق دامنه.
